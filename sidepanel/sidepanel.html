ログ

        
ページ内のfetch / XHRリクエストを自動キャプチャします。デフォルトはエラー（4xx/5xx/接続失敗）のみ表示。「全て」に切り替えると全リクエストを確認できます。

        
    
          
  • 行にカーソルを乗せるとステータス・URL・エラー概要のプレビューを表示
    • 
          
  • クリックで詳細（リクエスト/レスポンスヘッダー・ボディ・エラー解説）を確認
    • 
          
  • 詳細画面の「curlコマンド」欄でそのリクエストをcurlで再現できる形式にコピー
    • 
          
  • 詳細画面の「↺ 再送」で同じリクエストをページコンテキストから再実行
    • 
          
  • ↓ エクスポートで現在の表示ログをJSONファイルとして保存
    • 
          
  • ⚙ 除外フィルターで計測・広告などのURLをログから除外
    • 
        

      


      

        
JWT

        
URLパターンに一致するリクエストへ自動でAuthorizationヘッダーを付与します。ヘッダー名・プレフィックスは変更可能。

        
    
          
  • URLパターンはワイルドカード * に対応
    例: *://api.example.com/*
    • 
          
  • 有効期限（exp）はトークンから自動計算して一覧に表示
    • 
          
  • 「有効」状態のトークンのみ注入され、ログのリクエストヘッダーに反映
    • 
        

      


      

        
環境切り替え

        
ホスト名を自動置換してリクエスト先を切り替えます（Chrome の declarativeNetRequest を使用）。

        
    
          
  • 変換元ホスト → 変換先ホストを複数登録してまとめて管理
    • 
          
  • 「適用」で即時有効化、「環境OFF」で全ルールを解除
    • 
          
  • 例: api.example.com → api-dev.example.com
    • 
        

      


      

        
curlパーサー

        
curlコマンドを貼り付けるとメソッド・URL・ヘッダー・ボディに分解して見やすく表示します。チームから受け取ったcurlコマンドの確認などに便利です。

      


      

        
除外フィルター（⚙）

        
ログに記録したくないURLパターンを登録します。設定はブラウザ再起動後も保持されます。

        
    
          
  • ワイルドカード * を使用可能
    • 
          
  • 例: *google-analytics.com/* / *gtm.js* / *facebook.net*
    • 
        

      


      

        
エラー解説

        
4xx / 5xx / ネットワークエラー時、詳細画面の先頭に原因と対処法を自動表示します。

        
    
          
  • 401 では JWTタブの設定確認を案内
    • 
          
  • 対応コード: 0（接続失敗・CORS）/ 400–429 / 500–504
    • 
        

      


      

        
タグ付け

        
リクエストに自由なタグを付けて整理できます。詳細画面のタグ欄で入力・Enterで追加。

        
    
          
  • ログ一覧の行にタグチップが表示され、クリックでそのタグに絞り込み
    • 
          
  • ツールバー下のタグバーで一覧・切替が可能
    • 
        

      


      

        
ピン留め

        
重要なリクエストを右クリック → 「ピン / 解除」で先頭に固定できます。

        
    
          
  • ピン留め中のログは一覧の先頭に表示され ◈ マークが付く
    • 
          
  • ログクリア時にピンも解除されます
    • 
        

      


      

        
スナップショット（◈）

        
現在のログを名前付きで保存し、後から再現・比較できます。

        
    
          
  • ツールバーの ◈ ボタンで保存・読込モーダルを開く
    • 
          
  • 読込中はバナーが表示され「ライブに戻る」でリアルタイムに復帰
    • 
          
  • 最大30件まで保存可能（古いものから自動削除）
    • 
        

      


      

        
ボディ内検索（∋）

        
ツールバーの ∋ ボタンをONにするとURLに加えリクエスト・レスポンスボディ内テキストも絞り込み対象になります。
